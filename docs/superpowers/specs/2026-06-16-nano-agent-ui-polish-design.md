# 纳米毒性预测页面美化设计说明

## 目标

在不改变现有预测逻辑、解释逻辑和输入字段语义的前提下，重构 Streamlit 页面视觉层级与信息呈现方式，使页面同时满足两类场景：

- 日常研究录入：参数输入清晰、操作路径直接、结果易复核
- 学术展示汇报：截图稳定、结论突出、版面具有科研与学术语气

本次设计目标不是把页面做成营销化 landing page，而是做成“适合科研筛选与展示的单页工作台”。

## 用户与使用场景

主要用户：

- 进行纳米材料毒性筛选的研究人员
- 需要演示模型能力的导师、答辩或课程汇报使用者

主要场景：

- 输入实验参数，快速得到毒性等级、细胞活力和置信度
- 阅读智能体解释，判断结果是否具有进一步分析价值
- 在汇报或展示中直接使用页面截图呈现研究结论

## 设计方向

### 总体方向

采用“学术展示感”视觉路线，强调：

- 浅色背景与深色标题，提升学术排版质感
- 清晰的卡片边界与充足留白，避免默认 Streamlit 的工具页粗糙感
- 结果优先的阅读顺序，让页面在展示时先传达结论，再展开解释

页面应保留研究工具属性，但视觉表达更接近“论文附图 / 学术报告页”，而不是后台管理台或消费级产品页。

### 配色方案

确认采用“深蓝学术系”作为设计基线：

- 主色：`#0F172A`
- 辅色：`#334155`
- 强调色：`#0369A1`
- 页面背景：`#F8FAFC`
- 主正文：`#020617`

补充使用原则：

- 蓝色仅作为结构强调和交互焦点，不做大面积高饱和铺色
- 成功、警示、风险色仅用于毒性等级和重点状态提示，不参与主视觉竞争
- 阴影保持轻量，优先依赖边框、留白和层级建立秩序

### 字体与排版

字体风格以无衬线为主，强调稳重、清楚、适合中文科研语境：

- 标题：较强字重，负责建立页面气质与结论层级
- 正文：高可读中性无衬线，适合长解释文本阅读

排版原则：

- 一级标题突出页面主题与研究场景
- 二级标题用于划分输入区、结论区、解释区、特征区
- 数值信息比说明文字更大、更紧凑
- 避免大段等宽字体与终端式视觉表达

## 页面结构

页面重构为“顶部导语 + 主工作区”的结构。

### 顶部导语区

位于页面最上方，用于建立专业语境和首屏层级，包含：

- 页面标题：纳米材料毒性评估与解释
- 一行副标题：说明用途为肿瘤纳米药物筛选或临床前研究辅助
- 可选摘要标签：例如模型输出内容、适用场景、解释能力

该区域应克制，不做营销式大横幅，但要明显优于当前单行标题。

### 主工作区

主体采用双栏布局：

- 左栏：输入工作区
- 右栏：结果工作区

桌面端保持双栏，移动端自动纵向堆叠。

## 输入区设计

输入区保持研究录入效率优先，采用分组卡片而不是长串控件。

### 输入分组

建议分为四组：

1. 材料属性
   - 粒径
   - Zeta 电位
   - 材料类型
   - 表面修饰
2. 暴露条件
   - 暴露剂量
   - 暴露时间
3. 实验对象
   - 细胞类型
   - 来源物种
   - 组织来源
   - 检测方法
4. 解释增强
   - 是否使用可选 LLM 改写解释

### 交互方式

- 保持单次统一提交，而不是边改边预测
- 提交按钮应在输入区底部固定为主操作
- 输入标签和数值控件保持简洁，不加入无意义装饰

## 结果区设计

结果区采用已确认的“双层结构”。

### 上层：结论摘要 + 关键指标

这是页面最核心的展示区，位于结果区最上方，负责“一眼看懂结论”。

组成：

- 研究结论摘要
  - 一句高度凝练的结果结论
  - 示例语气：样本呈低毒性倾向，适合作为后续候选材料
- 三张关键指标卡
  - 毒性等级
  - 预测细胞活力
  - 模型置信度

设计要求：

- 结论文字优先级高于指标卡标签
- 指标卡统一风格，数值醒目，标签次级
- 毒性等级可使用轻量状态色区分，但不能破坏整体克制感

### 下层：解释 + 特征影响

下层负责展开分析，支持阅读和展示。

组成：

- 智能体解释卡片
  - 将当前纯文本输出转成更适合阅读的段落式内容
  - 保持原有文本含义，不改解释逻辑
- 特征影响卡片
  - 将当前逐行文本改为条形强度展示
  - 每个特征仍保留名称与数值信息

设计要求：

- 解释区适合长文本阅读，行高和留白要明显优于当前实现
- 特征区重点在“扫读效率”，而不是复杂图表
- 不引入新的数据计算逻辑，仅改变视觉表现

## 空状态与状态切换

### 未预测状态

右栏不应留空，应展示空状态卡片，内容包括：

- 当前页面可完成什么任务
- 需要填写哪些核心参数
- 预测后将输出哪些结果

空状态的作用是让页面在首次打开时也具备完整视觉结构。

### 已预测状态

点击预测后，右栏切换为正式结果视图：

- 首先显示结论摘要和关键指标
- 其次显示解释与特征影响

切换应平滑但克制：

- 允许轻微淡入或渐显
- 必须尊重 `prefers-reduced-motion`
- 动效时长控制在 150-300ms
- 不使用连续动画或夸张位移动画

## 视觉与可用性规则

### 视觉规则

- 不使用霓虹色、紫粉渐变、赛博风元素
- 不使用 emoji 作为图标
- 不依赖悬浮夸张缩放制造“高级感”
- 边框、层级和排版优先于重阴影和过度装饰

### 可用性规则

- 文字对比度达到可读标准
- 表单标签明确
- 键盘焦点态可见
- 按钮与交互元素尺寸足够
- 移动端不得出现横向滚动

## 响应式策略

桌面端：

- 顶部导语独立成区
- 主体双栏，左侧偏窄，右侧偏宽

平板与移动端：

- 输入区在上，结果区在下
- 关键指标卡可由三列收缩为单列或双列
- 长解释与特征条保持可读，不挤压到不可用

## 实现边界

本次允许改动：

- `app.py` 内部页面布局
- Streamlit 组件组织方式
- 样式注入与 CSS 变量
- 结果区的展示结构

本次不改动：

- 模型训练与预测逻辑
- 文献加载逻辑
- LLM 改写逻辑
- 输入字段定义与业务语义
- 预测结果数据结构

## 验证标准

完成后应满足以下标准：

- 页面在首屏即体现学术展示感，而非默认工具页
- 桌面端形成清晰的“输入 / 结果”双栏结构
- 结果区优先呈现研究结论，再展开解释
- 未预测和已预测两种状态都具备完整视觉层级
- 特征影响展示比当前逐行文本更易扫读
- 不改变现有预测调用链和解释生成逻辑

## 实施建议

实现时建议优先按以下顺序推进：

1. 建立全局样式变量与页面底色体系
2. 重构顶部导语区与主工作区布局
3. 重构输入区分组与提交区
4. 重构结果区双层结构
5. 将特征列表改为强度条可视化
6. 补充空状态、响应式和轻量动效
